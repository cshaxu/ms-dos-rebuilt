# COMMAND reconstruction status

`tfor.asm` is an unchanged copy of OpenNT's v86/cmd/command/tfor.asm, retained as the full module baseline. This is not a claim of original DOS 5 source. A reference assembly/link places its 718 code bytes at reference offset 0x38c1; comparison with target offset 0x2fdf finds 72 differing bytes, all in 52 external-reference words. No unmasked byte or internal-reference word differs. External symbol placement must still be reconstructed before this module can produce target bytes in a complete COMMAND build.

The earlier standalone ForOff experiment is preserved in tests/fixtures/foroff.asm and tests/foroff_slice.asm. Its fixed-address equates are test evidence, not production data layout. The COMMAND baseline and observed include/message dependencies have now been imported (109 files); all 34 local-source objects match the external reference objects byte for byte. The local probe reuses previously generated message files and external assembler, so a clean self-contained build is still pending. NT-specific source remains unmodified and must be reconstructed against the target. Provenance hashes and operand evidence are in docs/etc/evidence/m1-t2-tfor-source.json and m1-t2-tfor-module.json.
