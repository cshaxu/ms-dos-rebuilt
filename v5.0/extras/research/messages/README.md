# Earlier message inputs

These BIOS and kernel message files are retained for historical comparison.
The current BIOS and kernel use the shared `messages/usa-ms-dos.msg` and
generate indexes during the build; COMMAND uses its own usa-ms variant.
`dos/usa-ms-0420.idx` is the preserved pre-generated index.

`command/usa-ms-0419.idx` is the preserved pre-generated COMMAND index.
