# Architecture rules

Adapted from SoftPC `docs/rules/ARCHITECTURE.md`. Follow the ownership and provenance boundaries in the project architecture. Original input files remain immutable. OpenNT is the primary source baseline, not proof that each instruction is original DOS 5. Classify guest-to-host BOPs and replace them only with evidence-backed DOS paths; do not leave NT host dependencies in a claimed standalone DOS artifact. Preserve traceable origin and direct/inferred/unknown classifications. Review distribution rights separately from technical access.
