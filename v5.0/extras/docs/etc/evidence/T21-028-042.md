# T21 files 28-42

File 28, bios/sysinit2.asm, is accepted unchanged after reviewing all DOS6
diff hunks and consulting the corresponding OpenNT and DOS4 code.

| Difference | Decision |
| --- | --- |
| MULTI_CONFIG introduction, imports, parser branches, complete guarded menu implementation, state and alternate shells | Retain omission. DOS6 dates this feature 16-Mar-1992. It is not part of the frozen DOS5 target. The large deleted block is bounded by the original MULTI_CONFIG guard. |
| setparms DS setup, switches/drive accesses and EOT adjustment | Retain DOS5 instruction order and absence of the later EOT update, consistent with the accepted disk implementation. Moving DS setup would change instructions and segment overrides. |
| organize/mapcase | Retain whole-text uppercase mapping, REPE CMPSB and older return path. DOS6's per-line mapping preserves SET values and serves its added menu syntax. The retained comment accurately describes the selected implementation. |
| Question-mark queries, semicolon collapsing, block identifiers, DEVICEHIGH /L and INSTALLHIGH | Later parser features; do not introduce new accepted syntax or alter target branches. |
| org3 command checks | Retain COMMENT, INSTALL, DEVICE, SHELL order. Reordering to DOS6 changes target bytes without improving structure. |
| get2 | OpenNT lines 564-579 corroborate MOV AL,ES:[SI], INC SI, DEC CX and the ordinary end-of-input return. Do not substitute the DOS6 LODS instruction. |
| mem_err/cmdhalt | Existing cross-file entry in sysinit1, already audited as file 27. No second implementation. Retain caller and single loop. |
| command_line ownership and shell strings | Older data ownership is in sysinit1. Do not duplicate DOS6 command-line storage, lengths or alternate-shell data here. |
| comtab order and literal character codes | OpenNT lines 1557-1575 corroborate the older order and literal encoding; DOS4 also uses literal character codes. Keep this original style instead of gratuitously converting it to the DOS6 reordered symbolic table. OpenNT's subsequent ECHOCONFIG, NTCMDPROMPT and DOSONLY entries are correctly absent. |

No source edit was warranted. Existing procedure, conditional and comment
structure is retained. This unchanged file was compiled in the verified BIOS
stage t21-bios-21125-30761; all 15 BIOS objects and linked IO.SYS matched.
No new compilation is claimed for this unchanged review.

Files 29-42, bios/inc/arena.inc through bios/inc/msbds.inc, are raw-byte
identical to their frozen DOS6 reference files. The acceptance proof rechecks
both source and reference SHA256, in queue order. No changes or rebuilds.

A whole-word BOP/NTVDM/VDM/NTIO/dossvc scan of sysinit2.asm and bios/inc
returned no hits. Reference identity does not authorize NT host code.

Accepted prefix: 42/243; 4 modified and verified, 32 reference-identical,
6 necessary differences retained unchanged. Next: 43 bios/inc/mult.inc.
