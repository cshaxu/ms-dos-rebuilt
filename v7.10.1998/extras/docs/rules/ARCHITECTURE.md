# Architecture rules

The full v7.10.1111 source tree is the primary reconstruction workspace, initialized from audited v7.00.950. It is independent of the baseline source directory at build time. The pinned historical compiler/runtime remain external dependencies. v6.22, v6.20, v6.0, v5.0, DOS 4 and OpenNT are references where relevant. Record direct and inferred source provenance and preserve original Microsoft style. A baseline-identical file is not automatically verified against the 1111 target; source byte identity does not establish original authorship.
